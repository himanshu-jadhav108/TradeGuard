# Trade Review

Example:
BUY BTC
$500.00

Quote:
- BTC/USDC live price
- quote timestamp
- estimated base quantity
- quote expiry/staleness indicator

Portfolio:
- current BTC allocation
- projected allocation
- cash before/after
- concentration warning

Risk checks:
- balance sufficient
- supported asset
- max order size
- concentration threshold
- valid quantity/precision

AI explanation:
One or two factual sentences based only on backend-provided values.

Buttons:
- Cancel
- Confirm Trade

Confirmation must be an explicit user action. Never auto-submit.
