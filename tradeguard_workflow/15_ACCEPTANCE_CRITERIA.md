# Final Acceptance Criteria

A build is NOT finished until:
- premium landing page exists
- light/dark themes are polished
- responsive mobile/tablet/desktop layout
- demo mode works without credentials
- AI intent parsing is structured and validated
- deterministic risk engine works
- quote is shown with timestamp
- trade proposal is explainable
- explicit confirmation is required
- True Markets adapter is isolated
- UAT quote/balance/order/status tested if credentials are available
- secrets are backend-only
- order states are visible
- activity/audit exists
- E2E happy path passes
- README explains setup
- deployment works
- no fake claims
- no TODOs in the critical flow
- final code is clean and formatted
