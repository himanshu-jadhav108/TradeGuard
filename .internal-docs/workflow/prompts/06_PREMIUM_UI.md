# Antigravity Prompt 06 — Premium UI

Treat the UI as a premium fintech product.

Rebuild visual identity rather than copying the reference repository's appearance.

Requirements:
- elegant light/dark theme
- design tokens
- restrained palette
- strong typography
- subtle borders/shadows
- purposeful motion
- responsive
- keyboard accessible
- no purple AI gradients
- no giant chatbot hero
- no crypto-casino aesthetic
- no excessive glassmorphism

The Trade Review screen is the signature interaction.

Use the supplied branding assets.
