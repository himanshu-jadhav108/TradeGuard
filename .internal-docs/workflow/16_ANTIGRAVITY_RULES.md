# Antigravity Rules

1. Work phase-by-phase. Do not rewrite the whole project in one pass.
2. Before coding, inspect the workspace and produce an audit.
3. Create a git branch: `feat/tradeguard`.
4. Keep commits small and meaningful.
5. Run tests after each major phase.
6. Never invent True Markets endpoints. Use the current official docs/SDK.
7. If the documented API and an assumption conflict, stop and surface the conflict.
8. Never ask for or write secrets into files tracked by git.
9. Build DEMO mode before UAT.
10. Do not remove working functionality without replacing it.
11. Prefer simple architecture over speculative abstractions.
12. Do not add autonomous trading.
13. Do not add predictions/backtesting/RL unless explicitly requested later.
14. Do not add mobile apps.
15. Do not overbuild the database.
16. Premium UI is mandatory.
17. Use real product copy; no lorem ipsum.
18. No fake testimonials, performance, users, balances or partnerships.
19. Before final response, run lint/typecheck/tests/build and report results.
