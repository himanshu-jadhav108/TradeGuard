# Premium UI/UX System

## Product personality
Premium fintech. Calm, precise, trustworthy, editorial.

Reference feel:
- Apple-level restraint
- Linear-level product polish
- modern private-wealth terminal
NOT:
- crypto casino
- generic AI dashboard
- neon trading terminal
- purple gradient SaaS template

## Themes
Light:
- warm off-white canvas
- white elevated surfaces
- graphite text
- subtle neutral borders
- restrained emerald accent

Dark:
- near-black graphite canvas
- charcoal surfaces
- soft-white text
- subtle borders
- restrained emerald accent

Use CSS variables/design tokens. No hard-coded theme-specific colors scattered across components.

## Typography
Use a premium neutral sans font available from the web-safe/local stack. Strong hierarchy, generous line-height, restrained font weights.

## Motion
Short, purposeful transitions. No bouncing, excessive parallax, or distracting animations.

## Landing page
Headline: `Think before you trade.`
Subhead: `AI-assisted execution with live market context, deterministic risk checks, and human control.`
Primary CTA: `Try TradeGuard`
Secondary CTA: `Watch 2-min demo`

Hero should show the actual product UI, not an AI robot or abstract glowing orb.

## Core app navigation
- Overview
- Trade
- Portfolio
- Activity
- Settings

## Hero interaction
The Trade Review card is the signature interaction:
- side/asset
- amount
- live quote
- estimated fill
- portfolio impact
- risk checks
- concise AI explanation
- Cancel / Confirm Trade

## Accessibility
Keyboard navigation, visible focus states, semantic labels, sufficient contrast, reduced-motion support.
