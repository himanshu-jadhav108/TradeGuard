# TradeGuard Antigravity Workflow

This package is the single source of truth for building TradeGuard.

Start with `00_START_HERE.md`, then run prompts in `prompts/` sequentially.

Brand assets are in `branding/`.

The uploaded FinAlly ZIP is not bundled here because it is only a partial market-data subsystem; its reusable file inventory is documented in `reference/UPLOADED_REFERENCE_REPO.md`.

Never put True Markets credentials in this package.
